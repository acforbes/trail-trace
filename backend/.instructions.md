# FastAPI Backend Rules

## Code Style & Patterns
- Always use Python 3.11+ type hinting for function signatures and parameters.
- Prefer async route definitions (`async def`) unless executing synchronous blocking I/O operations.
- Leverage Pydantic v2 schemas for all request validations and response models.
- Always use explicit status codes from `fastapi.status` (e.g., `status.HTTP_201_CREATED`).

## GeoJSON & Mapping Constraints
- Coordinates must strictly adhere to the GeoJSON standard format: `[longitude, latitude]` (X, Y).
- Ensure validation logic checks that latitude is between -90 and 90, and longitude is between -180 and 180.

## Error Handling
- Never return generic HTTP 500 exceptions. Always raise specific `HTTPException` blocks with descriptive error details.
