# React + Leaflet Frontend Rules

## Core Ecosystem
- We use Vite with React 18+, functional components, and standard React hooks.
- For maps, strictly use the `react-leaflet` (v4+) layout wrapper elements (`MapContainer`, `TileLayer`, `Marker`, `Polyline`).

## React-Leaflet Design Rules
- CRITICAL: Always attach an explicit CSS height and width (e.g., `height: 100vh; width: 100%;` or `h-screen w-full`) to the map wrapper element. Leaflet maps will render with a height of 0px if unstyled.
- Never manipulate the underlying Leaflet map DOM directly using standard React refs. Use the `useMap` or `useMapEvents` hooks provided by `react-leaflet` to interact with the map instance.
- Prefer OpenStreetMap or CartoDB Map tile layer open-source endpoints for mapping backgrounds.

## State & API Fetching
- Maintain clean hook abstractions (like `useTrailFetch`) for calling the FastAPI endpoint.
- Always read the base API target URL from environment variables (`import.meta.env.VITE_API_URL`).
